## 📌 About the Project

Kayabrona is a full-stack e-commerce portfolio project adapted and customized from an existing open-source project.

The application is designed to provide a shopping experience where users can browse products, manage a shopping cart, register or log in, and place orders.

## ✨ Features

### Customer Features
- User registration and login
- Product catalog
- Product categories
- Shopping cart
- Order placement and order history
- Responsive user interface

### Admin Features
- Product management
- Category management
- Order management
- Inventory management

*Features depend on the implementation and configuration of the application.*
